登入金鑰產生器

在你自己的瀏覽器裡產生一組 ES256 金鑰，不會上傳到任何地方。

這把私鑰可以簽發任何人的登入憑證，請只貼到 Supabase 和 Cloudflare Worker 的機密 這兩個地方， 不要傳給任何人（包括 Claude），也不要存在雲端記事本。貼完後關掉這個頁面即可。
私鑰（JWK）
  1. Supabase → Project Settings → JWT Keys → Create Standby Key
  2. 演算法選 ES256，選 Import an existing private key，貼上這段，建立
  3. 在新金鑰右邊的「⋯」選 Move to previously used（只用來驗證，不影響 Supabase 自己的登入）
  4. Cloudflare → Worker → 設定 → 變數和機密 → 新增，類型選 機密 (Secret)，名稱 SUPABASE_JWT_PRIVATE_KEY，值貼上同一段
